# over the hill — Velvet Meridian

*A quiet companion for open-road configuration*

---

## 🎮 About the Game

over the hill is a cozy off-road exploration and driving game developed by Funselektor Labs Inc., released on October 14, 2026. It places players behind the wheel of vintage 4x4 vehicles from the 1960s through the 1980s across wilderness inspired by regions including Canada and Algeria. The atmosphere is relaxed and scenic, with forests, lakesides, mountains, changing weather, day-and-night cycles, wildlife, cabins, viewpoints, and meteorites shaping each journey. Driving focuses on exploration and overcoming rough terrain rather than competitive racing.

---

## 🔥 Project Overview

This local Windows application organizes configuration, profiles, and presets for over the hill without changing the game itself. It provides a calm workspace for preparing preferred driving arrangements while the mountains, forests, and weather remain on the other side of the road. This project is not a modification, not an overlay, and not a shortcut. Each option is applied through ordinary local files and user-controlled actions.

---

## ⚡ Features

### ⚙️ Configuration

- **Granite Climb** — Shapes how the vehicle handles steep grades and uneven ground, giving difficult ascents a more deliberate or forgiving character. The change is aimed at traction and clearance behavior on rugged trails.
- **Ember Winch** — Changes the feel of recoveries when the vehicle is pulled from a ditch, riverbank, or steep hollow. Cable reach and pull response can be tuned for patient exploration or quicker extraction.
- **Long Dusk** — Changes the balance between daylight and night travel, affecting how long the trails remain sunlit before headlights become essential. It is intended for players who prefer extended golden hours or deeper night runs.
- **Horizon Reserve** — Refines the selection and readiness of field tools carried by the vehicle, including recovery and repair equipment. It helps shape whether each outing favors preparedness, minimalism, or flexible problem solving.

### ⚡ Performance

- **Copper Tread** — Adjusts how the tires respond to loose soil, rock, mud, and wet paths. It gives the vehicle a firmer or softer relationship with the changing trail surface.
- **Falling Ember** — Shapes the arrival and extraction flow of fallen meteorites. Their pursuit can be paced for quiet searching or a more active trail-side interruption.

### 🔧 Maintenance

- **Timber Bridge** — Shapes how temporary planks assist with gaps and broken crossings. It keeps route improvisation central while adjusting the margin available when building a way across.
- **Iron Camp** — Adjusts the restorative role of cabins, camps, and field repairs after a demanding crossing. It changes how readily a prepared stop returns a worn vehicle to travel condition.

### 🖼️ Display

- **Rainbound Sky** — Adjusts the rhythm and intensity of changing weather across the wilderness. Clear intervals, rain, fog, and other conditions can be given a gentler or more prominent presence.
- **Cabin Palette** — Controls how strongly vehicle colors, accessories, and exterior details appear across the journey. The adjustment preserves the vintage character while allowing a quieter or more pronounced visual treatment.

### 🖥️ Interface

- **Quiet Compass** — Refines how route guidance and nearby points of interest present themselves during exploration. The road stays open-ended while directional assistance can be made subtler or clearer.
- **Wild Lens** — Changes the camera's assistance when framing wildlife and scenic subjects. Focus guidance and framing tolerance can be tuned for careful observation or quicker field captures.

---

> **Note:** The modules listed above are a curated selection. The full build includes additional controls that are not documented here. The documented set is intentionally partial.

## ❓ Frequently Asked Questions

**Q: Where should the utility be installed?**

A: Install it in a user-writable folder such as Documents or a dedicated applications folder. Avoid protected system directories when possible.

**Q: Does the utility change the game installation?**

A: It is designed to work with local configuration files and user-selected presets. Keep a backup of original files before applying changes.

**Q: Can I create separate profiles?**

A: Yes. Profiles can store different arrangements for driving, weather, display, and field equipment preferences.

**Q: Does the utility require an account?**

A: No account is required. The application is intended to run locally and does not require external services.

**Q: Can I use a controller while the utility is open?**

A: Yes. The utility is designed to remain separate from normal controller use, though hotkeys may be disabled when another application captures them.

**Q: How do I remove the utility?**

A: Use Windows Apps and Features or delete the installation folder after exporting any profiles you want to keep.

**Q: Are profiles preserved during updates?**

A: Updates should preserve user data when installed over the existing folder, but exporting profiles before an update is recommended.

## 🔧 Troubleshooting

| Problem | Solution |
| :--- | :--- |
| The application does not launch | Confirm that Windows is fully updated, install the .NET Desktop Runtime 8, and start the application from a user-writable folder. |
| A profile does not save | Check that the installation directory is writable and that the profile name contains no restricted characters. Export the profile and try saving it to Documents. |
| Hotkeys do not respond | Make sure the utility is running, the chosen keys are enabled, and another application is not capturing the same function keys. |
| The game feels slower after applying a preset | Return to the previous profile, reduce visual effects, and verify that the selected display options match the graphics hardware. |
| A localization choice does not apply | Close the game, apply the choice again, and restart both applications. Confirm that the selected language is supported by the game installation. |
| Old files remain after uninstalling | Remove the application's installation folder and delete its local data folder only after exporting profiles and presets you want to retain. |
